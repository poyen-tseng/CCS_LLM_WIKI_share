# 公開範圍與去識別

使用者選擇公開「程式＋技術文件＋去識別量測證據」。本次只處理新增 `projects/PWM_HW/` 及根目錄 README 的入口；沒有清理倉庫既有歷史或其他專案。

## 處理內容

- 排除姓名、組別、私人帳號、email、本機使用者路徑、私人 Drive 連結、儀器序號、內部 agent／訊息識別碼與核准對話欄位。
- 專案內檔案位置改為專案根目錄相對路徑；其餘私人主機路徑以佔位文字取代。個別歷史敘述可能提到未公開的檔案，並不代表其已包含在此副本。
- C2000Ware 安裝位置改成 `C2000WARE_ROOT`。TI 版權及授權聲明保留。
- PNG經目視檢查，為原生儀器畫面；未發現姓名／帳號，沒有 EXIF／作者／註解欄位。公開PNG保留原始位元組，未遮蓋、重畫或平滑波形。
- CSV的時間、電壓與計算數值保留；只有識別資訊／來源路徑可能變更。JSON移除私人欄位，其餘量測數值保留。

## 排除內容

不含課程原PDF、所有PPT／報告範本、被否決稿、聊天、agent記憶、工作流執行交接、私人IDE設定、金鑰、編譯輸出或原始證據壓縮包。未把待確認報告視為已核准成果。

## 雜湊與限制

[PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json) 對匯入的643個檔案列出公開SHA-256、來源SHA-256、大小及內容是否改變。新寫的說明文件不屬於來源檔對照。清理JSON或來源路徑會改變檔案雜湊；內嵌的歷史SHA有些指原私人檔，公開副本以manifest為準。

去識別檢查限於本次新增的內容及根目錄入口；未重新稽核整個repo及過去commit。日期、儀器型號、韌體版本、波形與技術設定因為重現與解讀需要而保留。此次沒有重新建置或驗證目前硬體狀態。
