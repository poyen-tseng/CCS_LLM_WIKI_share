# 示波器網路設定入口與歷史紀錄

現在的完整操作說明集中在 [Wiki：示波器網路設定](../../docs/wiki/scope-network-setup.md)，包含 Windows 網卡、RIGOL MSO5104 與 Keysight DSO-X 4034A 面板的 IP／遮罩／閘道／DNS、工具覆寫、連線驗證及疑難排解。初次接線或連不上時先讀該頁；本路徑保留，供既有 README 與 agent 指引使用。

2026-10-13 整理為入口與歷史紀錄，本次只做文件及靜態查核，未操作網卡或示波器。以下是當時結果，不代表目前連線、接上的機型或板上程式狀態。

## RIGOL：2026-10-07 只讀檢查與恢復連線

當時的狀態（2026-10-07 只讀檢查；之後已恢復連線）

| 項目 | 結果 | 意思 |
|---|---|---|
| 電腦「乙太網路」網卡 | Up，1 Gbps，IP 有 192.168.137.1，另有一個不相關的位址 | 電腦端已經設好 |
| bind 192.168.137.1 後送 `*IDN?` | 逾時 | 示波器沒有回應 |
| ARP 表（192.168.137.x，以及網卡上另一個不相關的網段） | **全部 Unreachable**，包含 .50 | 線的另一端沒有任何裝置回應 |

> 更正（同日稍晚實測）：示波器連上、`*IDN?` 正常回應時，網卡同樣顯示 **1 Gbps**。所以連線速度**不能**用來判斷線的另一端是不是示波器，請以 ARP 和 `*IDN?` 為準。

當時（連不上時）最可能的原因依序是：

1. 示波器沒開機。
2. 網路線沒接到示波器背面的 LAN 孔。
3. 示波器的 IP 設定被改掉了。

### 恢復後結果

2026-10-07 恢復連線後：`*IDN?` 回 `RIGOL TECHNOLOGIES,MSO5104` 與韌體版號，ARP 狀態 Reachable，網卡 1 Gbps，`pytest -m hw` 3/3 通過。

當時使用電腦有線網卡 `192.168.137.1/24` 直連 RIGOL `192.168.137.50:5555`，示波器遮罩 `255.255.255.0`、閘道 `192.168.137.1`。曾用 `:LAN:APPLy` 寫入固定 IP，紀錄指出重開機後保留；DNS 未記錄。此結果不能推定目前設定未變。

## Keysight：2026-10-12 首次連線

- 當時剛接上時為 DHCP＋AutoIP，示波器位址在 `169.254.x.x`；電腦使用 `192.168.137.1`，原先無法 ping 到。
- 從面板改為手動 IP `192.168.137.60`、遮罩 `255.255.255.0`、閘道 `192.168.137.1` 後，直連 `192.168.137.1` 的 ping 約 1–2 ms；DNS 未記錄。
- 綁定電腦 `192.168.137.1`、連 TCP `5025` 後，`*IDN?` 回覆 `AGILENT TECHNOLOGIES,DSO-X 4034A,...`；AGILENT 是舊品牌名。
- 網卡顯示 100 Mbps；速度本身不能證明連的是正確儀器。
